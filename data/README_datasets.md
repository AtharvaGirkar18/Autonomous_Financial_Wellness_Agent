# External Datasets for Testing

Use any of these free, real-world or realistic datasets to test the upload feature
beyond the built-in 18 synthetic users.

---

## ✅ Recommended: CSV Upload

The uploader accepts any CSV that has at least these columns
(column names are mapped automatically if close):

| Column | Required | Notes |
|---|---|---|
| `date` | ✅ | Any standard date format |
| `description` | ✅ | Transaction narrative / merchant name |
| `amount` | ✅ | Positive number (debit or credit) |
| `transaction_type` | ✅ | `DEBIT` or `CREDIT` (or `debit`/`credit`) |
| `category` | optional | Pre-labeled; if absent the ML categorizer runs |
| `merchant` | optional | Derived from description if absent |

## 🔄 Mapping Tips

If the downloaded CSV uses different column names, add a thin rename step
before uploading, or use the template below:

```python
import pandas as pd

df = pd.read_csv("your_downloaded_dataset.csv")

# Example rename for Kaggle "Bank Transaction Dataset"
df = df.rename(columns={
    "Date": "date",
    "Transaction Details": "description",
    "Withdrawal Amt.": "amount",
    "Deposit Amt.": "credit_amount",
})

# Mark withdrawals as DEBIT, deposits as CREDIT
df["transaction_type"] = df["Withdrawal Amt."].notna().map({True: "DEBIT", False: "CREDIT"})
df["amount"] = df["amount"].fillna(df["credit_amount"]).abs()

# Optional: add a user_id column
df["user_id"] = "EXTERNAL_USER"

df.to_csv("ready_to_upload.csv", index=False)
```

Then upload `ready_to_upload.csv` through the sidebar uploader.

## 📄 PDF Bank Statements

The PDF parser targets line-oriented statements generated by the built-in
ReportLab fixture generator. For real bank PDFs (HDFC, ICICI, SBI, Axis):

1. Export your net-banking statement as PDF.
2. The parser will extract any row that matches the pattern:
   `YYYY-MM-DD  <description>  <amount>  [DR|CR]`
3. Rows that don't match fall back to heuristic extraction.
4. If your bank uses a very different format, convert to CSV first
   (most banks offer CSV export directly).

## 🎯 Recommended Test Scenario

To fully test "Can I afford X?" and generative advisor responses:

1. Download the **Kaggle Personal Finance Dataset** (link above).
2. Rename columns as shown in the mapping tips.
3. Upload via the sidebar.
4. In the **AI Advisor** tab, type:
   - *"Can I afford a ₹10 lakh car?"*
   - *"How much can I save each month?"*
   - *"What is my biggest expense category?"*
   - *"Am I investment ready?"*

With a Gemini API key active, you'll get fluent AI-generated responses
grounded in your uploaded data. Without a key, the same questions return
fully deterministic calculations.
